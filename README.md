# Construction Risk Assistant

An AI-powered Python application that analyzes construction project risks and generates structured risk reports using the OpenAI API.

## Project Overview

The Construction Risk Assistant helps construction project managers analyze potential project risks by providing a risk description and a unique Risk ID.

The application uses AI to generate:
- Risk Description
- Probability
- Impact
- Risk Level
- Preventive Actions
- Response Plan
- Project Manager Recommendation

## Technologies

- Python
- OpenAI API
- python-dotenv

## Features

- Interactive risk input
- Unique Risk ID
- Automatic date recording
- AI-powered risk analysis
- Preventive action planning
- Risk response planning
- Project Manager recommendation
- Automatic TXT report generation
- Multiple risk analysis in one session
- Error handling
